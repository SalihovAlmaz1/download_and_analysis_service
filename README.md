# Download & Analysis Service

Cервис скачивает каталог текстовых файлов через внешнее API,
сохраняет их (диск + Postgres) и считает статистику встречаемости цифр в содержимом.

Внешнее API раздаёт файлы порциями, не даёт скачать всё разом и банит за
слишком частые запросы (`429`/`403` с `Retry-After`) — клиент это учитывает
и просто ждёт нужное время вместо падения.

## Что внутри

- **FastAPI** — бэкенд и API
- **SQLAlchemy + PostgreSQL (asyncpg)** — хранение метаданных о файлах
- **httpx** — клиент внешнего API скачивания
- Фронтенд — 2 самодостаточных HTML-файла (`src/static/`), без сборки и фреймворков

## Как запустить

### 1. Установить зависимости

Нужен [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

### 2. Поднять Postgres

Любой Postgres подойдёт, проще всего через Docker:

```bash
docker run -d --name dl_service_pg -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=app_db -p 5432:5432 postgres:16-alpine
```

### 3. Настроить `.env`

Скопируйте `.env.example` в `.env` и заполните своими значениями (там же
лежит `CANDIDATE_ID` — свой идентификатор кандидата для внешнего API,
если хотите отделить прогресс скачивания от IP).

### 4. Запустить сервис

```bash
uv run uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
```

При старте сервис сам создаст нужные таблицы в БД.

### 5. Открыть в браузере

- `http://127.0.0.1:8000/` — страница скачивания каталога
- `http://127.0.0.1:8000/files.html` — список скачанных файлов и расчёты
- `http://127.0.0.1:8000/docs` — Swagger UI по своему API

## Как пользоваться

1. На главной странице нажать «Скачать данные» — сервис в фоне пойдёт
   забирать файлы порциями, пока каталог не кончится. Наверху видно время
   старта (по Новосибирску) и счётчик «получено / скачано».
2. На странице «Файлы и расчёты» — таблица уже скачанных файлов
   (сортировка по времени скачивания, пагинация), три способа выбора
   (точечно чекбоксами, все на странице, вообще все файлы), кнопка
   «Произвести расчёты» — покажет статистику по цифрам суммарно и по
   каждому файлу отдельно.
